# Java RPG Battle Game

A console-based RPG battle game built in Java using Object-Oriented Programming principles.

## Features
- Multiple enemy types
- Abstract classes and inheritance
- Randomized combat
- File score saving
- Input validation

## Concepts Used
- OOP
- Inheritance
- Polymorphism
- Abstraction
- File handling
- Exception handling

## How to Run
1. Compile:
   javac RPGGame.java

2. Run:
   java RPGGame
